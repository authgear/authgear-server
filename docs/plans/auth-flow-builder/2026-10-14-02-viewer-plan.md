# Auth Flow Viewer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A flag-gated portal page at Authentication → Auth Flows that draws a project's effective auth flow for a chosen type and name, as a read-only left-to-right canvas of page sketches.

**Architecture:** Three pure functions turn flow config into what is drawn: `flowToTree` (config → sequence and branch tree), `treeToGraph` (tree → nodes and edges), and `layoutGraph` (tree + measured sizes → positions). `@xyflow/react` draws the result with custom React nodes. The screen loads `effectiveAppConfig` and `generatedAuthenticationFlows` in one query, resolves the flow the runtime would run, and keeps the selection in the URL.

**Tech Stack:** React 18, TypeScript, Radix Themes, `@xyflow/react` v12, `js-yaml`, Apollo (portal GraphQL), Jest with ts-jest, Storybook 10.

**Spec:** `docs/plans/auth-flow-builder/2026-10-14-01-viewer-design.md`

## Global Constraints

- Gate: `effectiveFeatureConfig.portal.auth_flow_builder_enabled`. The nav item and route exist only when it is true. The route uses `RequireAppFeature`, which redirects to Getting Started.
- Route `/project/:appID/configuration/authentication/flows`. Nav label "Auth Flows", placed after "2FA".
- URL selection: `?type=<signup_login|signup|login|promote|reauth|account_recovery>&name=<name>`. Unknown values fall back to `signup_login` and `default`.
- Flow resolution: a custom flow with the selected name wins. Otherwise, if the name is `default`, the generated flow is used. This mirrors `pkg/lib/authenticationflow/declarative/utils_common.go`.
- Branch order on the canvas is config order. Do not use dagre or elk.
- Read-only: no editing, saving, Render, Export or Publish.
- Every user-facing string goes in `portal/src/locale-data/en.json`. Message ids are literal strings in code or maps, so they can be grepped.
- Use the existing constants and sets, never copies. Read the config through the `types.ts` types.
- Never swallow an error. A broken invariant throws.

## Review Focus

1. **An optional step first in a branch** (login's 2FA step sits right after the Password option). The skip edge must leave from the option handle that leads into it. Pinned in Task 3.
2. **An empty choice mid-flow** (username-only account recovery). The steps after it have no incoming edge but must still be placed without overlapping. Pinned in Tasks 3 and 4.
3. **A choice whose branches are all empty** (`signup_login`). The node after it, here End, goes right after the choice node, not after a zero-width branch column. Pinned in Task 4.
4. **A `name` in the URL that exists only for another flow type** must fall back to `default`, not show an empty canvas. Pinned in Task 1.
5. **A custom flow named `default` together with the generated one** must not list `default` twice in the name picker. Pinned in Task 1.

```ts
import {
  AuthenticationFlowConfig,
  AuthenticationFlowsConfig,
} from "../../../types";

export const flowTypes = [
  "signup_login",
  "signup",
  "login",
  "promote",
  "reauth",
  "account_recovery",
] as const;
export type FlowType = (typeof flowTypes)[number];

export function isFlowType(v: unknown): v is FlowType {
  return typeof v === "string" && (flowTypes as readonly string[]).includes(v);
}

export const DEFAULT_FLOW_NAME = "default";
export const DEFAULT_FLOW_TYPE: FlowType = "signup_login";

const flowListKeys: Record<FlowType, keyof AuthenticationFlowsConfig> = {
  signup_login: "signup_login_flows",
  signup: "signup_flows",
  login: "login_flows",
  promote: "promote_flows",
  reauth: "reauth_flows",
  account_recovery: "account_recovery_flows",
};

function flowsOf(
  config: AuthenticationFlowsConfig | undefined,
  type: FlowType
): AuthenticationFlowConfig[] {
  return config?.[flowListKeys[type]] ?? [];
}

export type FlowSource = "custom" | "generated";

export interface ResolvedFlow {
  flow: AuthenticationFlowConfig;
  source: FlowSource;
}

// Mirrors the runtime: a custom flow with the name wins, and only "default"
// falls back to the generated flow.
export function resolveFlow(
  custom: AuthenticationFlowsConfig | undefined,
  generated: AuthenticationFlowsConfig,
  type: FlowType,
  name: string
): ResolvedFlow | null {
  const customFlow = flowsOf(custom, type).find((f) => f.name === name);
  if (customFlow != null) {
    return { flow: customFlow, source: "custom" };
  }
  if (name === DEFAULT_FLOW_NAME) {
    const generatedFlow = flowsOf(generated, type).find(
      (f) => f.name === DEFAULT_FLOW_NAME
    );
    if (generatedFlow != null) {
      return { flow: generatedFlow, source: "generated" };
    }
  }
  return null;
}

export function listFlowNames(
  custom: AuthenticationFlowsConfig | undefined,
  type: FlowType
): string[] {
  const names = [DEFAULT_FLOW_NAME];
  for (const flow of flowsOf(custom, type)) {
    if (!names.includes(flow.name)) {
      names.push(flow.name);
    }
  }
  return names;
}

export interface FlowSelection {
  type: FlowType;
  name: string;
}

export function parseFlowSelection(
  params: URLSearchParams,
  custom: AuthenticationFlowsConfig | undefined
): FlowSelection {
  const rawType = params.get("type");
  const type = isFlowType(rawType) ? rawType : DEFAULT_FLOW_TYPE;
  const rawName = params.get("name");
  const name =
    rawName != null && listFlowNames(custom, type).includes(rawName)
      ? rawName
      : DEFAULT_FLOW_NAME;
  return { type, name };
}

export function flowSelectionSearch(selection: FlowSelection): string {
  return `?${new URLSearchParams({
    type: selection.type,
    name: selection.name,
  }).toString()}`;
}
```

- `id` is the step's JSON pointer within the flow (`/steps/0/one_of/1/steps/0`). It is unique and stable.
- `branches === null` means the step is not a choice. `branches` set to `[]` means a choice with no options.

```ts
  AuthenticationFlowConfig,
  AuthenticationFlowOptionConfig,
  AuthenticationFlowStepConfig,
} from "../../../types";

export type StepKind = "page" | "pageless" | "unknown";

export interface FlowBranch {
  optionIndex: number;
  option: AuthenticationFlowOptionConfig;
  sequence: FlowStepItem[];
}

export interface FlowStepItem {
  // JSON pointer of the step within its flow.
  id: string;
  step: AuthenticationFlowStepConfig;
  kind: StepKind;
  optional: boolean;
  // null: not a choice. []: a choice with no options.
  branches: FlowBranch[] | null;
}

export const IDENTIFICATION_ID_TOKEN = "id_token";

const pageStepTypes = new Set([
  "identify",
  "authenticate",
  "create_authenticator",
  "verify",
  "fill_in_user_profile",
  "fill_form",
  "view_recovery_code",
  "prompt_create_passkey",
  "change_password",
  "select_destination",
  "verify_account_recovery_code",
  "reset_password",
]);

const pagelessStepTypes = new Set([
  "check_account_status",
  "terminate_other_sessions",
]);

// Steps whose options are required; a missing one_of is a choice with none.
const choiceStepTypes = new Set([
  "identify",
  "authenticate",
  "create_authenticator",
]);

function stepKind(step: AuthenticationFlowStepConfig): StepKind {
  if (pagelessStepTypes.has(step.type)) {
    return "pageless";
  }
  const oneOf = step.one_of ?? [];
  if (
    step.type === "identify" &&
    oneOf.length > 0 &&
    oneOf.every((o) => o.identification === IDENTIFICATION_ID_TOKEN)
  ) {
    return "pageless";
  }
  if (pageStepTypes.has(step.type)) {
    return "page";
  }
  return "unknown";
}

function sequenceToTree(
  steps: AuthenticationFlowStepConfig[],
  pointer: string
): FlowStepItem[] {
  const items: FlowStepItem[] = [];
  steps.forEach((step, i) => {
    const id = `${pointer}/${i}`;
    const oneOf = step.one_of ?? [];
    const optional = step.optional === true;
    const kind = stepKind(step);
    // An optional step keeps its single option as a branch, so skipping it
    // also skips the option's nested steps.
    if (oneOf.length === 1 && !optional) {
      items.push({ id, step, kind, optional, branches: null });
      items.push(
        ...sequenceToTree(oneOf[0].steps ?? [], `${id}/one_of/0/steps`)
      );
      return;
    }
    if (oneOf.length === 0 && !choiceStepTypes.has(step.type)) {
      items.push({ id, step, kind, optional, branches: null });
      return;
    }
    items.push({
      id,
      step,
      kind,
      optional,
      branches: oneOf.map((option, j) => ({
        optionIndex: j,
        option,
        sequence: sequenceToTree(option.steps ?? [], `${id}/one_of/${j}/steps`),
      })),
    });
  });
  return items;
}

export function flowToTree(flow: AuthenticationFlowConfig): FlowStepItem[] {
  return sequenceToTree(flow.steps ?? [], "/steps");
}
```

```ts
import { FlowStepItem, StepKind } from "./tree";

export const START_NODE_ID = "start";
export const END_NODE_ID = "end";
export const NEXT_HANDLE_ID = "next";

export function optionHandleID(optionIndex: number): string {
  return `option-${optionIndex}`;
}

export type GraphNodeKind = "start" | "end" | StepKind;

export interface FlowGraphNode {
  id: string;
  kind: GraphNodeKind;
  item: FlowStepItem | null;
}

export type FlowGraphEdgeKind = "next" | "option" | "skip";

export interface FlowGraphEdge {
  id: string;
  source: string;
  sourceHandle: string;
  target: string;
  kind: FlowGraphEdgeKind;
  optionIndex: number | null;
}

export interface FlowGraph {
  nodes: FlowGraphNode[];
  edges: FlowGraphEdge[];
}

// An outlet is an edge waiting for its target: whatever comes next.
interface Outlet {
  source: string;
  sourceHandle: string;
  kind: FlowGraphEdgeKind;
  optionIndex: number | null;
}

export function treeToGraph(tree: FlowStepItem[]): FlowGraph {
  const nodes: FlowGraphNode[] = [
    { id: START_NODE_ID, kind: "start", item: null },
  ];
  const edges: FlowGraphEdge[] = [];

  const connect = (outlets: Outlet[], target: string) => {
    for (const o of outlets) {
      edges.push({
        id: `${o.source}:${o.sourceHandle}:${o.kind}->${target}`,
        ...o,
        target,
      });
    }
  };

  const walk = (sequence: FlowStepItem[], incoming: Outlet[]): Outlet[] => {
    let current = incoming;
    for (const item of sequence) {
      nodes.push({ id: item.id, kind: item.kind, item });
      connect(current, item.id);
      let outlets: Outlet[];
      if (item.branches == null) {
        outlets = [
          {
            source: item.id,
            sourceHandle: NEXT_HANDLE_ID,
            kind: "next",
            optionIndex: null,
          },
        ];
      } else {
        outlets = item.branches.flatMap((b) =>
          walk(b.sequence, [
            {
              source: item.id,
              sourceHandle: optionHandleID(b.optionIndex),
              kind: "option",
              optionIndex: b.optionIndex,
            },
          ])
        );
      }
      if (item.optional) {
        outlets = [
          ...outlets,
          ...current.map((o) => ({ ...o, kind: "skip" as const })),
        ];
      }
      current = outlets;
    }
    return current;
  };

  const last = walk(tree, [
    {
      source: START_NODE_ID,
      sourceHandle: NEXT_HANDLE_ID,
      kind: "next",
      optionIndex: null,
    },
  ]);
  nodes.push({ id: END_NODE_ID, kind: "end", item: null });
  connect(last, END_NODE_ID);
  return { nodes, edges };
}
```

```ts
import { FlowStepItem } from "./tree";
import { END_NODE_ID, START_NODE_ID } from "./graph";

export interface Size {
  width: number;
  height: number;
}

export interface Position {
  x: number;
  y: number;
}

export const GAP_X = 80;
export const GAP_Y = 40;

const EMPTY: Size = { width: 0, height: 0 };

// Lays the tree out left to right. A choice stacks its branches top to bottom
// in config order, and the step after it starts right of the widest branch.
export function layoutGraph(
  tree: FlowStepItem[],
  sizes: ReadonlyMap<string, Size>
): Map<string, Position> {
  const sizeOf = (id: string): Size => {
    const size = sizes.get(id);
    if (size == null) {
      throw new Error(`layoutGraph: no size for node ${id}`);
    }
    return size;
  };

  const boxes = new Map<FlowStepItem[] | FlowStepItem, Size>();

  const sequenceBox = (sequence: FlowStepItem[]): Size => {
    const cached = boxes.get(sequence);
    if (cached != null) {
      return cached;
    }
    let box = EMPTY;
    sequence.forEach((item, i) => {
      const b = itemBox(item);
      box = {
        width: box.width + (i > 0 ? GAP_X : 0) + b.width,
        height: Math.max(box.height, b.height),
      };
    });
    boxes.set(sequence, box);
    return box;
  };

  const stackHeight = (item: FlowStepItem): number =>
    (item.branches ?? []).reduce(
      (sum, b, i) => sum + (i > 0 ? GAP_Y : 0) + sequenceBox(b.sequence).height,
      0
    );

  const itemBox = (item: FlowStepItem): Size => {
    const cached = boxes.get(item);
    if (cached != null) {
      return cached;
    }
    const node = sizeOf(item.id);
    const branchWidth = Math.max(
      0,
      ...(item.branches ?? []).map((b) => sequenceBox(b.sequence).width)
    );
    const box = {
      width: node.width + (branchWidth > 0 ? GAP_X + branchWidth : 0),
      height: Math.max(node.height, stackHeight(item)),
    };
    boxes.set(item, box);
    return box;
  };

  const positions = new Map<string, Position>();

  const placeNode = (id: string, x: number, centerY: number) => {
    positions.set(id, { x, y: centerY - sizeOf(id).height / 2 });
  };

  const placeItem = (item: FlowStepItem, x: number, centerY: number) => {
    placeNode(item.id, x, centerY);
    const branches = item.branches ?? [];
    if (branches.length === 0) {
      return;
    }
    const branchX = x + sizeOf(item.id).width + GAP_X;
    let top = centerY - stackHeight(item) / 2;
    for (const b of branches) {
      const height = sequenceBox(b.sequence).height;
      placeSequence(b.sequence, branchX, top + height / 2);
      top += height + GAP_Y;
    }
  };

  // Returns the x just past the last placed item.
  const placeSequence = (
    sequence: FlowStepItem[],
    x: number,
    centerY: number
  ): number => {
    let cursor = x;
    sequence.forEach((item, i) => {
      if (i > 0) {
        cursor += GAP_X;
      }
      placeItem(item, cursor, centerY);
      cursor += itemBox(item).width;
    });
    return cursor;
  };

  placeNode(START_NODE_ID, 0, 0);
  const firstX = sizeOf(START_NODE_ID).width + GAP_X;
  const afterTree = placeSequence(tree, firstX, 0);
  placeNode(END_NODE_ID, tree.length > 0 ? afterTree + GAP_X : firstX, 0);
  return positions;
}
```

```tsx
const AuthFlowsScreen: React.VFC = function AuthFlowsScreen() {
  const { appID } = useParams() as { appID: string };
  const { renderToString } = useContext(Context);
  const { data, loading, error, refetch } = useAuthFlowsScreenQueryQuery({
    variables: { id: appID },

  const app = data?.node?.__typename === "App" ? data.node : null;
  const appConfig = app?.effectiveAppConfig as PortalAPIAppConfig | undefined;
  const custom = appConfig?.authentication_flow;
  const generated = app?.generatedAuthenticationFlows as
    | AuthenticationFlowsConfig
    | undefined;

    () => parseFlowSelection(searchParams, custom),
    [searchParams, custom]
  );
  const names = useMemo(
    () => listFlowNames(custom, selection.type),
    [custom, selection.type]
  );
```

```tsx
import React, { useContext, useEffect, useMemo, useState } from "react";
import {
  Background,
  Controls,
  Edge,
  MiniMap,
  ReactFlow,
  ReactFlowProvider,
  useNodesInitialized,
  useNodesState,
  useReactFlow,
} from "@xyflow/react";
import "@xyflow/react/dist/style.css";
import { Context } from "../../../intl";
import { FlowStepItem } from "./tree";
import { FlowGraphEdge, treeToGraph } from "./graph";
import { layoutGraph, Size } from "./layout";
import { FlowNode, flowNodeTypes } from "./FlowNodes";
import { optionLabel } from "./labels";
import styles from "./FlowCanvas.module.css";

const SKIP_EDGE_DASH = "6 4";

export interface FlowCanvasProps {
  tree: FlowStepItem[];
  selectedStepID: string | null;
  onSelectStep: (id: string | null) => void;
}

function FlowCanvasInner({ tree, selectedStepID, onSelectStep }: FlowCanvasProps) {
  const { renderToString } = useContext(Context);
  const graph = useMemo(() => treeToGraph(tree), [tree]);
  const [nodes, setNodes, onNodesChange] = useNodesState<FlowNode>(
    graph.nodes.map((n) => ({
      id: n.id,
      type: n.kind,
      position: { x: 0, y: 0 },
      data: { item: n.item },
    }))
  );
  const nodesInitialized = useNodesInitialized();
  const { getNodes, fitView } = useReactFlow<FlowNode>();
  const [laidOut, setLaidOut] = useState(false);

  // First render is hidden; once xyflow has measured every node, lay out and show.
  useEffect(() => {
    if (!nodesInitialized || laidOut) {
      return;
    }
    const sizes = new Map<string, Size>();
    for (const n of getNodes()) {
      if (n.measured?.width == null || n.measured.height == null) {
        throw new Error(`FlowCanvas: node ${n.id} was not measured`);
      }
      sizes.set(n.id, { width: n.measured.width, height: n.measured.height });
    }
    const positions = layoutGraph(tree, sizes);
    setNodes((ns) =>
      ns.map((n) => ({ ...n, position: positions.get(n.id) ?? n.position }))
    );
    setLaidOut(true);
  }, [nodesInitialized, laidOut, getNodes, setNodes, tree]);

  useEffect(() => {
    if (laidOut) {
      // fitView rejects only if the instance is gone, which an unmount explains.
      fitView().catch((e: unknown) => {
        console.error(e);
      });
    }
  }, [laidOut, fitView]);

  const selectedNodes = useMemo(
    () => nodes.map((n) => ({ ...n, selected: n.id === selectedStepID })),
    [nodes, selectedStepID]
  );

  const edges = useMemo(
    () =>
      graph.edges.map((e: FlowGraphEdge): Edge => {
        const option =
          e.optionIndex != null
            ? graph.nodes.find((n) => n.id === e.source)?.item?.step.one_of?.[
                e.optionIndex
              ]
            : undefined;
        return {
          id: e.id,
          source: e.source,
          sourceHandle: e.sourceHandle,
          target: e.target,
          type: "smoothstep",
          label:
            e.kind === "skip"
              ? renderToString("AuthFlowsScreen.edge.skip")
              : e.kind === "option" && option != null
              ? optionLabel(option, renderToString)
              : undefined,
          style:
            e.kind === "skip" ? { strokeDasharray: SKIP_EDGE_DASH } : undefined,
        };
      }),
    [graph, renderToString]
  );

  return (
    <div
      className={styles.canvas}
      style={{ visibility: laidOut ? "visible" : "hidden" }}
    >
      <ReactFlow<FlowNode>
        nodes={selectedNodes}
        edges={edges}
        nodeTypes={flowNodeTypes}
        onNodesChange={onNodesChange}
        nodesDraggable={false}
        nodesConnectable={false}
        edgesFocusable={false}
        onNodeClick={(_, node) =>
          onSelectStep(node.data.item != null ? node.id : null)
        }
        onPaneClick={() => onSelectStep(null)}
        minZoom={0.2}
      >
        <Background />
        <Controls showInteractive={false} />
        <MiniMap pannable={true} zoomable={true} />
      </ReactFlow>
    </div>
  );
}

export function FlowCanvas(props: FlowCanvasProps): React.ReactElement {
  return (
    <ReactFlowProvider>
      <FlowCanvasInner {...props} />
    </ReactFlowProvider>
  );
}
```

```ts
import { FlowStepItem } from "./tree";

export function findStep(
  tree: FlowStepItem[],
  id: string
): FlowStepItem | null {
  for (const item of tree) {
    if (item.id === id) {
      return item;
    }
    for (const branch of item.branches ?? []) {
      const found = findStep(branch.sequence, id);
      if (found != null) {
        return found;
      }
    }
  }
  return null;
}
```
